# 商业方案

TokenFactory 相关商业与战略说明材料。

## 页面

| 文件 | 说明 |
|------|------|
| [商业模式演进.html](./商业模式演进.html) | 算力租赁 → 训练工厂 + Token 工厂 演进示意图 |
| [index.html](./index.html) | 入口（跳转至商业模式演进） |

## 本地预览

在项目根目录执行：

```bash
npx --yes serve 商业方案 -p 4173
```

浏览器打开：http://localhost:4173/商业模式演进.html

也可直接用浏览器打开 `商业模式演进.html` 文件（需联网加载 Tailwind CDN）。
