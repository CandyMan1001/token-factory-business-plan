| 文件 | 说明 |
|------|------|
| [商业模式演进.html](./商业模式演进.html) | 算力租赁演进 + 训推一体合作方案 + token 阶梯计费 |

## 本地预览

在项目根目录执行：

```bash
npx --yes serve 商业方案 -p 4173
```

浏览器打开：http://localhost:4173/商业模式演进.html

也可直接用浏览器打开 `商业模式演进.html` 文件（需联网加载 Tailwind CDN）。
